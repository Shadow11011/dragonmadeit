How should the homepage flow?

Editorial design breaks the typical SaaS "hero → features → pricing" stack. Which structure fits?

A

Split Narrative

Hero splits asymmetrically — big serif headline on left, dashboard preview on right. Then alternating content blocks (text-left/visual-right, then swap). Each section is its own "spread" like turning pages. Pricing lives in a dedicated band at the bottom.

Inspired by: Vercel's split layouts + magazine spreads

Broadsheet

Full-width sections but with newspaper-like density. Hero is a massive serif headline with minimal whitespace around it — the text IS the design. Below, content organized in multi-column blocks like a newspaper front page. Features displayed as a 2-column text grid (no cards, no icons). Stats woven into prose. Dense but well-spaced.

Inspired by: WIRED/The Verge editorial density

Chapter Book

The page is divided into distinct "chapters" separated by full-width dividers with chapter labels (like "01 — How It Works"). Each chapter has its own layout rhythm — one might be a split, another a full-bleed image, another a text column. Creates a reading experience, like scrolling through a well-designed pitch deck. The user feels like they're reading a story, not scanning a landing page.

Inspired by: Ferrari/Lamborghini editorial + pitch decks
